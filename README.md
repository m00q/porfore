【概要】
Flutter Webで制作中の個人ポートフォリオです。
経歴や技術を並べるだけではなく、インタラクションや可視化を通して、どのように学び、実装しているかを表現することを目指しています。

【目的】
ポートフォリオ自体を一つの開発成果物として作り、
PokéLabではデータ構造やアルゴリズムの動作過程を自分で実装し、視覚的に表現します。

【理由】
完成した結果だけではなく、
問題を理解し、構造を考え、動作の過程まで説明できる開発者を目指しているためです。

【核心の一文】
結果だけでなく、過程が見えるポートフォリオ。

【スローガン】
作ったものを面白くするためには、作ること自体も面白く。

===============================================================================

[개요]
Flutter Web으로 제작 중인 개인 포트폴리오입니다.
경력과 기술을 단순히 나열하기보다, 인터랙션과 시각화를 통해 제가 어떤 방식으로 배우고 구현하는지를 보여주는 것을 목표로 합니다.

[목적]
포트폴리오 자체를 하나의 개발 결과물로 만들고,
PokéLab을 통해 자료구조와 알고리즘의 동작 과정을 직접 구현하고 시각적으로 표현합니다.

[이유]
완성된 결과만 보여주는 것보다,
문제를 이해하고 구조를 설계하며 동작 과정을 설명할 수 있는 개발자가 되고 싶기 때문입니다.

[핵심 한 줄]
결과보다 과정이 보이는 포트폴리오.

[슬로건]
만든 것이 재미있으려면, 재미있게 만들어야 한다.
